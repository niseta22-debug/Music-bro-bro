FNF MUSIC STUDIO — исходный Android Studio проект

Что уже есть:
- Piano Roll на 16 шагов и 13 высот нот
- 4 синтезируемые дорожки: Lead, Bass, Keys, Drums
- BPM 60–240, громкость, воспроизведение
- экспорт WAV (4 такта)
- сохранение/открытие проекта JSON
- офлайн-работа, без рекламы и разрешений на интернет

Размер:
Проект очень маленький; итоговый APK должен быть значительно меньше 220 МБ.
Звуки синтезируются самим приложением, поэтому большие библиотеки семплов не нужны.

Как получить APK:
1. Установить Android Studio на компьютер.
2. Открыть папку FNF_Music_Studio через File -> Open.
3. Дождаться Gradle Sync (при первом запуске нужен интернет для загрузки Android Gradle Plugin).
4. Выбрать Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. APK появится в app/build/outputs/apk/debug/app-debug.apk.

Минимальная версия Android: 6.0 (API 23).
Рекомендуемая проверка: Android 12.
Важно: в этой среде нет Android SDK/Gradle, поэтому готовый APK здесь не собран.
