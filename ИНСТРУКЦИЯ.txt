FNF MUSIC STUDIO — проект для сборки APK через GitHub Actions

В архиве уже есть:
- папка app/ с Android-приложением;
- папка .github/workflows/ с автоматической сборкой APK;
- настройки Gradle;
- инструкция.

Загрузка:
1. Распакуйте архив.
2. Загрузите ВСЁ содержимое этой папки в корень репозитория GitHub.
3. Убедитесь, что в репозитории видны build.gradle, settings.gradle, app/ и .github/.
4. Откройте вкладку Actions.
5. Выберите Build Android APK (если запуск не начался автоматически, нажмите Run workflow).
6. После завершения откройте запуск workflow и скачайте FNF-Music-Studio-APK в Artifacts.

Важно:
- Не загружайте ZIP как один файл — сначала распакуйте.
- При загрузке скрытая папка .github должна сохраниться.
- Android Studio на вашем ПК не нужна.
- APK создаётся на серверах GitHub.
